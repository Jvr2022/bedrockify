# Google Search

An initial Ore UI pass for Google Search, based on the selectors supplied for the
search buttons and search box.

The library import is pinned to a commit so later library changes do not affect
this style. Build with `npm run build`, then install `dist/styles/google/bedrockify.user.css`
in Stylus. Check the search page in your browser; Google changes its markup and
this style has not been visually tested yet.
